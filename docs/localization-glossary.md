# Mixly localization glossary

Use this glossary for public website copy, blog posts, and release notes.

| Concept | English | German |
| --- | --- | --- |
| Кальянный микс | hookah mix / mix | Shisha-Mix / Mischung |
| Табак для кальяна | hookah tobacco | Shisha-Tabak |
| Вкус, вкусовой профиль | flavor / flavor profile | Aroma / Geschmacksprofil |
| Крепость | strength / preferred strength | Stärke / bevorzugte Stärke |
| Чаша кальяна | bowl | Bowl |
| Лаборатория (функция) | Lab | Labor |
| Открытия (функция) | Discovery | Discovery |
| Подборка миксов | feed / recommendations | Auswahl / Empfehlungen |

## Style

- Use **mix** consistently in English; reserve **blend** for a specific mixture only when needed.
- Use **Aroma** for an individual flavor in German; use **Geschmack** for the overall taste experience.
- Keep the feature names **Lab** and **Discovery** capitalized.
- Prefer direct, conversational wording. Do not translate Russian idioms or syntax literally.
